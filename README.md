# IRON REBELLION · Последний рубеж

Браузерный 2D Run & Gun на HTML, CSS, JavaScript и Phaser 3. Сервер на Node.js и Socket.IO ведёт общий бой и хранит прогресс в SQLite.

Версия 0.1 включает одну законченную миссию «Зелёный ад» для двух игроков и режим одиночной тренировки. На пути к аванпосту HELIOS вертолёт обстреливает мост и обрушивает два пролёта. За мостом ждут бункер, щитоносцы и два генератора, которые запирают ворота к двухфазному танку «Бульдог-01». Вторая фаза открывает реактор на крыше танка. За скрытый тайник у моста команда получает дополнительные кредиты.

В кооперативе оба игрока наносят урон одним и тем же противникам. Рэй может рывком пройти под обстрелом, Алекс устанавливает турель. Рядом с выведенным из строя союзником удерживайте **E** три секунды. Когда из двух бойцов на ногах остаётся один, он на десять секунд быстрее передвигается и перезаряжается.

## Запуск на компьютере

Установите Node.js 22.13 или новее. Распакуйте архив, откройте терминал в папке `iron-rebellion` и выполните команды:

```bash
npm ci
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере. Для запуска игры сервер должен работать. Для проверки вдвоём на одном ПК откройте обычное окно и окно инкогнито либо два разных профиля браузера. В обычных вкладках одного профиля используется одна и та же игровая учётная запись.

## Как сыграть вдвоём

1. На первом устройстве выберите бойца и нажмите «Создать комнату».
2. На втором устройстве откройте тот же адрес игры и введите код комнаты. Ссылка из лобби сразу подставит код.
3. Оба нажмите «Готов». После этого командир нажимает «Начать миссию».

Если устройства в одной локальной сети, откройте на обоих `http://IP_компьютера_с_сервером:3000`. На Windows узнать адрес можно командой `ipconfig`. После входа по этому адресу ссылка из лобби будет содержать локальный IP, доступный второму устройству. Если не удаётся подключиться, проверьте, разрешает ли брандмауэр входящие подключения на TCP-порт 3000 в частной сети.

В ту же комнату можно вернуться после перезагрузки страницы или обрыва связи. Сервер резервирует место на три минуты. Активные комнаты находятся в памяти сервера и закрываются при его перезапуске. Покупки и кредиты остаются в SQLite. Профиль распознаётся по ключу, который хранит браузер для текущего адреса игры.

## Публикация для игры через интернет

Разместите папку `iron-rebellion` на хостинге, который запускает Node.js и пропускает WebSocket. Настройки для Node.js Web Service, например на Render:

| Настройка | Значение |
| --- | --- |
| Рабочая папка | Каталог с `package.json` |
| Версия Node.js | 24 LTS или версия не ниже 22.13 |
| Команда сборки | `npm ci` |
| Команда запуска | `npm start` |
| Проверка состояния | `/healthz` |
| Количество экземпляров | 1 |
| `PORT` | Порт, назначенный хостингом |
| `DATA_DIR` | Путь к постоянному тому для SQLite |

После запуска откройте публичный HTTPS-адрес сервиса на обоих устройствах. Используйте один экземпляр сервера, поскольку состояние активных комнат хранится в его памяти. Постоянный том для `DATA_DIR` нужен, чтобы кредиты и покупки переживали замену контейнера. Обычный статический хостинг отдаёт страницу, но для общего боя требуется работающий сервер из проекта. [Документация Render Web Services](https://render.com/docs/web-services)

Для хостинга с Docker можно собрать и запустить образ:

```bash
docker build -t iron-rebellion .
docker run --rm -p 3000:3000 -v iron-rebellion-data:/app/data iron-rebellion
```

## Оружие и награды

В начале доступны AR-17 «Штурм» и резервный пистолет с бесконечным запасом патронов. SG-8 «Гром» стоит 500 CR, MG-40 «Мясорубка» стоит 900 CR. Купленное оружие нужно снарядить в арсенале перед следующим запуском. Каждое основное оружие имеет пять уровней. Пятый даёт пробитие противников для винтовки и дробовика. У пулемёта каждый десятый выстрел наносит двойной урон.

Команда получает 10 CR за обычного врага, 30 CR за щитоносца и 100 CR за тайник. Победа над танком и завершение миссии дают ещё 500 CR каждому участнику. Игрок, которого ни разу не вывели из строя, получает 150 CR дополнительно. Поражение сохраняет кредиты за уже побеждённых врагов и найденный тайник.

## Код

| Путь | Назначение |
| --- | --- |
| `client/index.html`, `client/style.css` | Экраны, HUD и оформление |
| `client/main.js` | Меню, комнаты, магазин и результаты |
| `client/play.js`, `client/art.js` | Phaser, ввод, звук и отрисовка пиксельной графики |
| `client/data.js` | Карта и общие параметры |
| `server/game.js` | Движение, столкновения, враги, бой и события |
| `server/server.js` | HTTP, Socket.IO, комнаты и начисление наград |
| `server/profile.js` | SQLite, покупки и снаряжение |

Сервер принимает ввод и считает позиции, попадания, награды и состояние миссии с частотой 30 тиков в секунду. Клиенты интерполируют позиции для плавной отрисовки. Графика и звуковые эффекты созданы в коде.

Пять последующих миссий, два дополнительных персонажа и комнаты на четыре места относятся к расширенной кампании из ТЗ.
